# Quesería La Castreña — demo

Demo de tienda online para Quesería La Castreña (Islares, Cantabria).
Web estática de un solo archivo servida con Cloudflare Workers (assets).

Producción: https://castrena-demo.agencia39700.workers.dev

## Desplegar

    npx wrangler deploy

O automáticamente con Workers Builds al hacer push a `main`.

## Pendiente antes de entregar

- Cambiar las fotos de muestra (generadas con IA) por fotos reales del obrador.
- Denominación fiscal, NIF, domicilio y registro sanitario para el aviso legal.
- Confirmar precios, tarifas de envío y plazos con la quesería.
- Revisión de los textos legales por su asesoría.
